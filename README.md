# MTG Inv — support hub

This repository is the public support hub for **MTG Inv**, a Magic: The Gathering collection, deck and market tracker
(web app plus iPhone and Android apps).

**The application code is private.** This repo holds only support conversations: bug reports, feature requests and
questions.

## How to get help

- **Something broke?** [Report a bug](../../issues/new?template=bug_report.yml). The "Report a problem" link inside the
  app opens this form with your app version and platform already filled in.
- **Want something added?** [Request a feature](../../issues/new?template=feature_request.yml).
- **Questions, ideas, announcements?** Use [Discussions](../../discussions).
- **No GitHub account?** Use the "no GitHub? email" link next to "Report a problem" in the app.

## Please don't post private data

Issues and discussions here are public. Don't include passwords, tokens, your email address, or screenshots that show
account details. Describe what you saw; we'll ask for more if needed.
